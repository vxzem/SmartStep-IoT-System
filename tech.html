// MODULAR ARCHITECTURE

Integrated Subsystem Modules

Each tile functions as an autonomous energy collection unit capable of daisy-chaining into continuous multi-square-meter floor installations.

MODULE 01

PZT Transducer Matrix

Arrays of 35mm PZT-5H ceramic discs bonded to brass flex-substrates. Arranged in parallel-series configurations to withstand pedestrian shear forces.

  • Material PZT-5H Ceramic
  • Output Range 12V – 22V AC pk
  • Deflection Tolerance 1.5mm max
MODULE 02

Schottky Bridge Rectifier

Ultra-fast switching Schottky diodes (VF < 0.28V) rectify high-impedance AC pulses into filtered DC current with minimal thermal leakage.

  • Forward Drop (Vf) 0.24V @ 100mA
  • Capacitance Buffer 470µF 35V Low-ESR
  • Rectification Eff. >85%
MODULE 03

ESP32 IoT Gateway

Integrated ESP32 dual-core microcontroller with 802.11 b/g/n Wi-Fi and Bluetooth BLE. Features hardware wake-on-interrupt to maximize sleep power savings.

  • Sleep Current ~15 µA (Deep Sleep)
  • Telemetry Protocol HTTPS REST / WSS
  • Cloud Backend Supabase Edge
